Homestead Overlay Planner

Help & Instructions

Quick Start

  1. Click the extension icon, then click Start Planning.
  2. If you are not on Google Maps, a Maps tab opens automatically.
  3. Enter a plan name to create your plan.
  4. Draw with the in-map toolbar, then adjust shapes in Select mode.
  5. Use Save any time. Auto-save also runs while you edit.

Toolbar Tools

  • Select: Select, move, resize, rotate (non-circles), edit, and rename labels.
  • Pan Mode: Pan the map without editing overlay shapes.
  • Lasso: Drag a lasso box to select many items at once.
  • Connection: Click one line endpoint, then another endpoint, to connect lines.
  • Line: Click-drag to create one segment.
  • Rectangle: Click-drag diagonal corners to create a rectangle.
  • Circle: Click-drag diameter endpoints to create a circle.
  • Polygon: Click to add points, double-click to finish.
  • Label: Click to place a label. Tool auto-switches to Select after placement.
  • Delete Selected: Removes current selection.
  • Save / Exit: Save immediately or exit planning mode.

Select, Multi-Select, Lasso

  • Click a shape or label to select it. Shift + Click adds/removes items in selection.
  • Ctrl/Cmd + A selects all overlay shapes and labels.
  • Drag any selected shape to move the whole selection together.
  • In Lasso mode, drag to select items inside/intersecting the lasso box.
  • In Lasso mode, Shift + Drag appends to existing selection.
  • Delete or Backspace removes selected items.

Editing Shapes

  • In Select mode, click a line/rectangle/circle/polygon to show its draggable control points.
  • Drag vertex handles to reshape geometry.
  • Rectangle corner dragging preserves right angles and resizes as a rectangle.
  • Non-circle selected shapes show rotate handle (R); click-hold-drag to rotate.
  • Double-click a length badge to set an exact side length (or circle diameter).
  • Double-click a label to rename it.
  • Drag label bubble to move it; drag label resize handle to resize the label box.

Measurements, Area/Length Visibility, Units

  • Line shows length. Rectangle/polygon show side lengths and area. Circle shows diameter and area.
  • Lengths: On/Off toggles all length labels globally.
  • Areas: On/Off toggles all area labels globally.
  • Show/Unshow Length mode lets you click a specific side to toggle only that length.
  • Show/Unshow Area mode lets you click a rectangle/polygon/circle to toggle only that area.
  • Units: Metric/Imperial switches units live; your preference is saved locally.
  • Default units are chosen by browser locale: US = imperial, non-US = metric.

Polygon Right-Angle Assist

  • While drawing a polygon, a 90° indicator appears when the next segment is near perpendicular.
  • Hold the right-angle snap key (default: A) to force the next segment to 90°.
  • You can remap this key in popup Key Bindings.

How To Draw A Polygon

  1. Click Polygon in the toolbar (or press G).
  2. Click once on the map to place the first corner.
  3. Move the cursor, then click again to place the next corner.
  4. Keep clicking to add all remaining corners.
  5. Double-click to finish and close the polygon.
  6. Optional: hold A while placing a side to force a right angle.
  7. If you need to cancel before finishing, press Esc.

Shapes Panel (In-Map Navigator)

  • The Shapes panel is collapsible and starts collapsed by default.
  • Drag the panel header to move it anywhere on screen.
  • The panel remembers its collapsed/expanded state and screen position.
  • Each item has Find: saves current plan, moves map to that item, and keeps panel state/position.

Save, Auto-Save, Storage

  • Plans are stored locally in chrome.storage.local (no cloud backend by default).
  • Auto-save runs after create/move/resize/rotate/delete/copy-paste/undo-redo/toggle edits (debounced).
  • Save performs an immediate save.
  • Use popup Export JSON for backups and Import JSON for restore/migration.

Troubleshooting

  • If planner UI does not appear, refresh Google Maps and click Start Planning again.
  • If saving fails with an extension-context error after extension reload/update, reopen popup and start planning again.
  • Status messages auto-dismiss after a short delay. If an error repeats, export JSON as a backup.
  • Keep a JSON export backup for important plans.
